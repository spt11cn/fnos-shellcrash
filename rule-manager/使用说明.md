# ShellCrash 规则管理器 · 使用说明

一个 Windows 单文件图形程序，用来管理飞牛 NAS 上 ShellCrash 的**自定义策略组**和**自定义规则**。
它和你之前的「ShellCrash 部署器」是两套独立程序，互不冲突（本工具默认端口 8801，部署器 8799）。

## 它能做什么

| 功能 | 说明 |
|---|---|
| 内核当前状态 | 实时显示内核是否运行、版本、运行时长、内存/CPU、代理模式、活跃连接数、累计上下行流量、TUN 状态、各监听端口、转发与 DNS 模式。可随时点「刷新」，重启内核后自动更新 |
| **自定义策略组** | 新建 / 删除策略组（select / url-test / fallback / load-balance），成员可从全部节点里下拉选或手填；写入 `yamls/proxy-groups.yaml`，**重启内核后自动合并生效，订阅更新不会冲掉** |
| 自定义规则增删改 | 图形化添加 / 按行号删除 / 直接编辑整个 `yamls/rules.yaml`。新加的规则放在规则表最前面，优先匹配 |
| 现有规则分组显示 | 规则列表按 `# ===== 分组标题 =====` 分类展示，能看清每条规则属于哪个分组（如淘宝放行、苹果服务等） |
| 策略组可选可填 | 「策略组」支持下拉选择和手动输入两种；旁边有独立「刷新」按钮，可从 NAS 重新读取，刷不出来也能直接手填 |
| 自动备份 | 每次改动规则前自动生成带时间戳的 `.bak` 备份 |
| 重启内核 | 规则改完后点一下「重启内核使规则生效」即可，不用 SSH 敲命令 |

## 怎么用

1. 双击 `ShellCrash规则管理器.exe`，浏览器会自动打开 `http://127.0.0.1:8801/`。
2. 第 1 步填飞牛 NAS 的地址、用户名、密码（sudo 密码默认同登录密码，不同才填下面那栏），点**连接**。
   - 密码可以勾选「记住」，用 Windows DPAPI 加密保存，只有当前系统账户能解开。
3. 连接成功后会自动读取自定义策略组和规则：
   - **新建自定义策略组**（第 3 项）：填组名、选类型；成员从「选择节点/策略组」下拉里逐个「加入」，或直接在成员框里用逗号分隔填写；点「新建策略组」。现有自定义组在左侧列表，点「删」可删除。
   - **加规则**（第 4 项）：填类型（如 `DOMAIN-SUFFIX`）、值（如 `mclick.simba.taobao.com`）、目标策略组（如 `DIRECT`），点「添加」。也可以点「放行到 DIRECT」「加入拦截」等快捷按钮。策略组一栏支持下拉选择或手动输入，旁边「刷新」按钮可从 NAS 重新读取。
   - **删规则**：在右侧列表找到那一行，点「删」。
   - **高级**：两个卡片底部都有文本框，可直接改整个文件后点「保存文本改动」。
4. **自定义策略组、规则改完，一定要点对应卡片的「重启内核使...生效」按钮**。
5. **关闭网页即可自动退出程序**，不用手动结束进程（约 3 秒后自动关闭；刷新网页不会误关）。也可以点右上角「退出程序」立即退出。

## 自定义策略组说明

- 写入位置：`/etc/ShellCrash/yamls/proxy-groups.yaml`（ShellCrash 官方的自定义策略组文件）。
- 生效方式：点「重启内核使策略组生效」后，ShellCrash 会自动把它合并进运行时配置；**订阅更新不会冲掉**，比手改 `config.yaml` 安全。
- 成员名填节点名（如 `香港01`）或已有策略组名（如 `🚀 节点选择`、`DIRECT`）都可以。
- 类型说明：`select` 手动选择；`url-test` 自动测速选最快；`fallback` 故障转移；`load-balance` 负载均衡（后三者可填测速地址和间隔）。
- 建好后还需要到「第 4 项 自定义规则」里加一条规则把流量指到这个新组，才会真正被使用。

## 典型场景

**场景一：淘宝广告链接打不开**

客户机 DNS 指向 NAS 后，某些链接被广告规则拦了。两种做法：

- 精准：只加一条规则 `- DOMAIN-SUFFIX,mclick.simba.taobao.com,DIRECT`，然后重启内核。

**场景二：某个内网服务想让它直连不走代理**

添加规则：`DOMAIN-SUFFIX,你的域名,🎯 全球直连` 或 `DIRECT`，重启内核。

## 出错怎么办

- **SSH 认证失败**：飞牛 NAS 用的是系统账号（和你 SSH 登录的一样），不是应用中心的账号。
- **连接超时**：确认 NAS 开机、IP 正确、22 端口开着。
- **规则改了没生效**：规则必须重启内核才生效；策略组切换不用。
- **想撤销规则改动**：改之前自动备份在 NAS 的 `/etc/ShellCrash/yamls/rules.yaml.bak.时间戳`，可以 SSH 上去覆盖回去，或用「保存文本改动」把备份内容贴回去。
- **程序启动报端口占用**：8801-8820 被别的程序占了，关掉占用程序再试。

## 技术实现

- Windows 端：Python 标准库 `http.server` + `paramiko`，PyInstaller `--onefile --noconsole` 打包。
- NAS 端：内嵌的 Python 助手脚本以 root 运行，负责读写 `yamls/rules.yaml` 和调用外置控制器（默认 `127.0.0.1:9999`，从运行时配置自动读取）。
- 策略组选择由 mihomo 写入 `/etc/ShellCrash/cache.db`，所以重启后保持。
