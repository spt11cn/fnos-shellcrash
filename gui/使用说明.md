# ShellCrash 部署器（图形版）

双击 `ShellCrashDeployer.exe`，会自动在浏览器里打开操作界面（http://127.0.0.1:8799）。

## 三步走

1. **选 NAS**：点「扫描局域网」，列表里带绿色 `飞牛 fnOS` 标签的就是，点一下自动填好地址和网段；扫不到就直接手填 IP。
   > 如果 NAS 和电脑不在同一网段（比如电脑在 192.168.11.x、NAS 在 192.168.1.x），把上面的网段改成 `192.168.1` 再扫；直接在「NAS 地址」里输入 IP 会自动同步网段。
2. **填凭据**：飞牛的登录用户名、密码（sudo 密码留空表示与登录密码相同）。
3. **点按钮**：
   - `① 环境体检` —— 只读，不改任何东西。先看这一屏，确认 CPU/网卡/端口都正常
   - `② 一键部署` —— 需要填网段；订阅可留空，装完在菜单里导入
   - `③ 验证连通` —— 在 NAS 上建临时命名空间模拟客户机，测完自动清理
   - `卸载回滚` —— 停服务、清防火墙规则、删文件、还原本地别名

日志实时滚动，绿=正常、黄=注意、红=错误。

## 版本记录

**v1.5**
- 修复「`ping` 通但共享文件夹打不开」：跨网段转发现在会自动做 SNAT（`nat POSTROUTING MASQUERADE`），
  把客户机源地址改写成本机地址，内网服务器回包不再走丢。SMB 445、SSH 这类需要完整三次握手的服务受益最明显
- 放行规则不再限制来源网段：任何网段（`192.168.31.x`、`10.x`）的客户机只要网关指向 NAS 都能访问内网服务器
- 每次应用规则时自动清理残留 conntrack（旧的失败连接会绕过新增的 NAT 规则）
- 体检新增「跨网段 SNAT」状态；验证脚本第 7 步可实测某台内网服务器的 445/139

**v1.4**
- 修复「改了网关后访问不了其它网段的服务器」（例如 NAS 在 192.168.1.x、服务器在 192.168.0.5）：飞牛装了 Docker 会把 iptables `FORWARD` 策略设成 DROP，NAS 于是不转发任何跨网段流量。体检会提示，部署时自动插入 `sc-lan-forward` 规则放行内网网段，并注册 `shellcrash-lan-forward.service` 开机重建
- 验证脚本新增第 7 步「内网互访」，直接告诉你转发是否被 DROP 挡住

**v1.3**
- 新增「退出程序」按钮（页面右上角）：点一下结束后台进程，不再是关掉浏览器标签就留个僵尸进程
- 页面每 10 秒发一次心跳；关掉标签页后 3 分钟无心跳且无任务在跑，程序自动退出
- 重复双击不再开出第二个进程：检测到已有实例就直接打开它的页面；检测到旧版占用端口会弹窗提示先结束旧进程
- 有任务在执行时拒绝退出，避免半途中断部署

**v1.2**
- 登录失败不再甩英文堆栈，改成中文原因 + 排查清单（用户名/密码/SSH 是否允许该账号）
- 新增「记住密码」：勾选后**登录成功时**才用 Windows DPAPI 加密存盘，下次启动自动填好；取消勾选立即清除。配置里只有密文，换台电脑/换个 Windows 账号解不开
- 密码框加 `autocomplete="new-password"`，避免浏览器自动填充成别的网站存过的密码（这类自动填充是登录失败最常见的原因）
- 状态栏对登录失败单独提示，不再显示「退出码 -2」

**v1.1**
- 修复日志乱码：远端脚本的颜色转义（`\x1b[36m` 之类）在网页里会显示成方块，现在由程序解析成对应颜色级别后剥掉；脚本自身检测到非终端输出时也不再发颜色码
- 体检改为以 root 执行，端口占用能直接显示进程名（如 `CrashCore（pid=1760187）`）
- 同一代理内核占用的多个端口合并成一条提示，不再刷四行
- 隐藏 sudo 的密码提示行

**v1.0** 首个版本

## 说明

- 程序只监听 `127.0.0.1`，局域网内其它机器访问不到。密码默认不保存；勾选「记住密码」后以 Windows DPAPI 加密存到 `%APPDATA%\ShellCrashDeployer\config.json` 的 `pwd_enc` 字段，只有当前 Windows 账号能解密。
- 部署完在 NAS 上执行 `crash` 进管理菜单（首次需 `unalias crash` 或重开 SSH）。
- 客户端设置：网关 + DNS 都填 NAS 的局域网 IP。
- 退出程序：点页面右上角「退出程序」。**直接关浏览器标签不会结束后台进程**（会残留，直到 3 分钟无心跳自动退出）。旧版没有这个按钮，只能在任务管理器里结束 `ShellCrashDeployer.exe`。
- 卸载程序本身：删掉 exe 即可，配置在 `%APPDATA%\ShellCrashDeployer\config.json`。

## 命令行模式（可选）

```bash
ShellCrashDeployer.exe --scan 192.168.1
ShellCrashDeployer.exe --cli --action check --host 192.168.1.100 --user 用户名 --pwd 密码
```
